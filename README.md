# An Ethical and Emotionally Intelligent Social Media Plugin

A collaborative AI-powered plugin for the **Open Source Social Network (OSSN)** that integrates multiple responsible AI components to promote safer, more ethical, and emotionally intelligent online interactions.

🌐 **Project Website:** https://sensai-website.vercel.app/

---

## Overview

This project presents a centralized AI-powered plugin that brings together four intelligent components into a unified social media moderation and user-support platform. Developed as a collaborative Honours research project, the system combines **Responsible AI (RAI)** and **Explainable AI (XAI)** principles to improve online safety, enhance user well-being, and support transparent decision-making within social media environments.

Each component was independently researched and developed before being integrated into a single FastAPI-powered architecture and deployed within the Open Source Social Network (OSSN).

---

## Key Components

- 🛡️ **Cyberbullying Detection**  
  Detects harmful and abusive content using multimodal AI techniques.

- 🤖 **Behavior-Based Social Bot Detection**  
  Identifies malicious social bot accounts through behavioral analysis and lifecycle-aware risk assessment.

- 😊 **Emotion-Aware Interaction**  
  Analyzes user emotions to encourage healthier and more empathetic online interactions.

- 👥 **Explainable Friend Recommendation**  
  Generates transparent friend recommendations with human-understandable explanations.

- ⚡ **Unified FastAPI Backend**  
  Integrates all AI components through a centralized backend architecture.

- 🌐 **OSSN Integration**  
  Deploys the complete AI framework as an integrated plugin within the Open Source Social Network platform.
